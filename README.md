# Чтение старинных документов моделями

Сайт замера: как большие языковые модели читают русские метрические книги и ревизские сказки
XVIII-XIX веков. Статья, полная таблица конфигураций и диаграмма «цена против качества» с фильтрами.

- `content/` — текст статьи и её диаграммы;
- `data/` — числа: `arms.json` (все конфигурации), `results.json` (строки интерактивной диаграммы);
- `static/` — оформление и код диаграммы;
- `docs/` — собранный сайт, его и раздаёт GitHub Pages.

Сборка: `uv run --no-project --with markdown python build.py`.
Обновление чисел и диаграмм: `python sync.py <чекаут корпуса> <папка отчёта>`.

Инструменты корпуса, из которого взят набор, собраны в библиотеке [verso](https://github.com/verso-genealogy/verso).
