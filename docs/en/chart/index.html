How to read the chart

What the chart shows

Each point is a configuration: a model at an effort level. The horizontal axis is the price of reading 100 records through the batch API, the vertical axis is errors per 100 name fields: given name, patronymic and surname. Lower and further left is better. A line joins one model's effort levels.

Configurations read twice are shown as the mean of the two runs.

Measures

Silent errors: a wrong name that the model did not flag. This is the main number. All errors: wrong names, flagged or not. Flagged errors: wrong names that the model itself doubted.

Proofreading cost adds up silent errors and flags: a silent error counts as one, every flagged field as 0.3, whether it is right or wrong. It shows how much work is left for a person after the model.

What counts as an error

A script compares what was read with the reference, there is no LLM judge. Small differences in spelling are forgiven: Сергѣевъ and Сергеев count as the same reading, Димитрій and Дмитрій as variants of one name. An error is a different name, a missed field or an invented person.

Intervals

The bar at a point is the 95% confidence interval, computed by resampling the records. On 167 records a difference of about 2.5 errors per 100 names can be detected. If the bars of two points overlap, the points should not be treated as different.
